# Engine faces

One small line drawing per engine, drawn for Zeist Chess from the engine's name or its own emblem: a fish for
Stockfish, a bulb for Halogen, a birch leaf for Koivisto, a crown for Arasan. They are not the engines' logos.
24 by 24, one stroke color, shown in bone on graphite. The Zeist engine uses the Zeist Chess mark instead.
File names are engine ids. AGPL-3.0-or-later, like the app.
