# Maia 3

Maia-3 is a transformer trained on Lichess games to predict the move a human of a given rating would play. This pack runs it as a UCI engine.

- Model: `maia3_simplified.onnx` (45,683,686 bytes, sha256 `405bf76c15727dad8728b352c06a8f3c1b80fb2760e8d666b32485c63d75b856`, 22.7 million fp16 parameters, opset 17), taken unchanged from https://github.com/CSSLab/maia-platform-frontend at commit 8b91abf4646788ed53edd471a37c20b8d8c94d94 (`public/maia3/`). `build.sh` fetches it from that commit and refuses any other bytes. It is the file the Maia authors' own site runs in the browser.
- What is known about the model, and what is not (checked 2026-11-19):
  - Upstream added it in commit 24b3e96e ("Add maia3 simplified ONNX model (86.8MB, fp32)") and made it half precision in 0013cc8e ("Switch to fp16 ONNX model"). Neither commit, nor the repository's README, says which training checkpoint it was exported from.
  - Its layers have the shapes of the published 23M models (8 layers, width 512). It takes 355 input features a square, as `UofTCSSLab/Maia3-23M-ponder` does (`maia3-23m-ponder.pt`, sha256 `0ac9fb74…281bd1`, Hugging Face revision 34ec2be9); `UofTCSSLab/Maia3-23M` (`maia3-23m.pt`, sha256 `bce6cd1a…fb3569`, revision 51a0145a) takes 352.
  - Its weights are not those of either published file. Compared tensor by tensor with each checkpoint cast to half precision: none of Maia3-23M's tensors match; Maia3-23M-ponder's are close (the nearest differ by less than 0.001) but not equal (0.007% of values the same). So it is a Maia-3 model of the 23M size with the ponder variant's inputs, and not a copy of a checkpoint published on Hugging Face. This pack claims no more than that.
- Model license: the file is published by its authors (CSSLab, University of Toronto) in a repository under GPL-3.0 (`LICENSE-maia-platform.txt`), with no separate notice for the model; those are the terms these bytes are distributed under here. The Maia-3 code and published checkpoints are AGPL-3.0: the Hugging Face model cards (for example https://huggingface.co/UofTCSSLab/Maia3-23M) say "see repo for code/weights license", and the repo https://github.com/CSSLab/maia3 (commit 1e13597c42d4858b7cfd7cfdae01e297263364b2) carries the AGPL-3.0 `LICENSE`, shipped as `LICENSE-maia3.txt`. The pack's manifest therefore names the network's license as GPL-3.0-only (the repository carries the GPL-3.0 text and says nothing of later versions). Both licenses' texts ship in the pack. GPL-3.0 and AGPL-3.0 works may be combined (section 13 of each).
- Code: `worker.js` is this repo's (AGPL-3.0-or-later). Its input encoding and move indexing follow the platform's `src/lib/engine/tensor.ts` (GPL-3.0). Vendored: onnxruntime-web 1.23.0 from npm (MIT, `LICENSE-onnxruntime.txt`; the version the Maia platform uses) and chess.js 0.12.1 from npm (BSD-2-Clause, `LICENSE-chess.js.txt`) for legal moves.
- Patched: nothing upstream. The worker caps onnxruntime's shared WebAssembly memory at 256 MB, as the platform does for iPhones, runs one thread, and uses graph optimization level `basic`.
- How it plays: `go` (any limits) runs the network once and plays the legal move with the highest policy, so it is repeatable. `info` lines carry the top moves (`MultiPV` 1 to 10), a score from the value head, and an `info string policy` line with probabilities.
- Strength: `UCI_Elo` 600 to 2600 is the rating Maia imitates. `Opponent Elo` (0 means the same) is the rating it assumes for the other side. `UCI_LimitStrength` is accepted and has no effect.
