# Calibration results

Every level of every engine rated on Maia 3's scale: Maia plays the move its network gives a player of the set rating (UCI_Elo 600 to 2600), so a number here means "scores 50% against Maia set to this". It is Maia's scale, not a Lichess or FIDE rating. Generated by `engines/calibrate/fit.mjs`; how the games are played is in `engines/calibrate/run.mjs` and `play.mjs`.

Each cell: the maximum likelihood rating and its 95% interval. "above 2600" / "below 600": the whole interval is past the end of Maia's range, after at least 12 games there; the evidence is in the details. Levels still playing show their games so far.

Fitted 2026-11-15 01:35 UTC.

How it is run (DIR holds the game records and logs, outside the repo):

```sh
node --test engines/calibrate/test/*.test.mjs                 # the rating math
node engines/calibrate/sanity.mjs maia --low 1300 --high 1700 --data DIR
node engines/calibrate/sanity.mjs determinism --engine zeist
nohup node engines/calibrate/all.mjs --data DIR --jobs 6 > DIR/logs/all.log 2>&1 &   # every engine, resumable
node engines/calibrate/run.mjs <engine> --levels 1-10 --data DIR                     # one engine
node engines/calibrate/fit.mjs --data DIR                                            # this page
```

## Sanity checks

- Maia 1700 against Maia 1300, 48 games: Maia 1700 scored 37.5 (78.1%, 9 draws); the 400-point gap predicts 90.9%. Fitted from these games, Maia 1700 rates 1521 (1409-1649). Longest game 123 plies.
- Maia 1200 against Maia 800, 48 games: Maia 1200 scored 34 (70.8%, 10 draws); the 400-point gap predicts 90.9%. Fitted from these games, Maia 1200 rates 954 (850-1068). Longest game 135 plies.
- Maia 2400 against Maia 2000, 48 games: Maia 2400 scored 33 (68.8%, 16 draws); the 400-point gap predicts 90.9%. Fitted from these games, Maia 2400 rates 2137 (2034-2248). Longest game 151 plies.
- So Maia's settings are closer together in strength than their numbers say: a 400-point step played like 221, 154, 137 Elo points (34% to 55% of the gap). The ratings above are Maia settings, the point where an engine level scores 50%, and stay comparable with each other. The intervals assume the logistic model, which takes each Maia point as one Elo point, so read in Maia settings they are too narrow by roughly that factor.
- Determinism, stockfish-lite level 3 against Maia 1500, opening 0, seed 267658913: same workers after another game gave a different game; fresh workers gave a different game. Expected from the engine, not the harness: with UCI_LimitStrength on, Stockfish weakens its play through a random generator seeded from the clock (Skill::pick_best, as in the Fairy-Stockfish source, which shares it), so its limited levels do not repeat. Level 10 (no limit) should repeat; not checked.
- Determinism, ethereal level 3 against Maia 1500, opening 0, seed 267658913: same workers after another game gave a different game; fresh workers gave the same game. Fresh workers repeat the game; a worker reused after another game does not, so Ethereal keeps some search state across ucinewgame. The app also keeps a worker across games.
- Determinism, zeist level 3 against Maia 1500, opening 0, seed 267658913: same workers after another game gave the same game; fresh workers gave the same game. The harness itself is repeatable: same workers, fresh workers, same game.
