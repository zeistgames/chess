# Pieces: Zeist

Zeist's own chess set: the king with a curled rim under a cross, the queen with a curled coronet, the classic
knight, the waisted rook, and the bishop and pawn of the same family. It is the default set in Zeist and in
Zeist Chess.

Drawn from scratch for Amrith in November 2026; not traced or adapted from any other set. Copyright Amrith.
In this repository the set is licensed under the AGPL-3.0-or-later, like the app.

The drawings are made in Zeist's own repository and copied here one way. A drawing that needs changing is
changed there, never here.
