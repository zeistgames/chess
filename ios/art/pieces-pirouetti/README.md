# Pieces: Slender

The chess pieces drawn by pirouetti (https://lichess.org/@/pirouetti) for Lichess, as published in Lichess's
`public/piece/pirouetti` (https://github.com/lichess-org/lila/tree/master/public/piece/pirouetti), taken at
commit 27c7f8d9fb1a04a2d8a23d8c3378a15e21ee9a54. The set was contributed to Lichess itself; its only published
source is Lichess. Lichess's COPYING.md (https://github.com/lichess-org/lila/blob/master/COPYING.md) records:

    public/piece/pirouetti | [pirouetti](https://lichess.org/@/pirouetti) | AGPLv3+

That is the GNU Affero General Public License, version 3 or later (https://www.gnu.org/licenses/agpl-3.0.txt),
the same license as this app.

The files here are unmodified. `ios/scripts/pieces.py` recolors them in Zeist's ivory and ebony with a soft
light and a fine rim, and renders the images the app uses.
